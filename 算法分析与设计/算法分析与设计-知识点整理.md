## 1. 绪论（Introduction）

> 📌 **老师划线**：成绩构成 **Final exam 50% / Practices and others 50%**；Advice 红字：本课 **high load**、**Read the lecture notes carefully**（讲义比教材更有用）。

### 1.1 基本概念

- **问题（Problem）**：从输入到对应输出的数学函数；同一输入必须总是得到相同输出；问题定义应包含对解所消耗资源的限制。
- **三类问题**：
  - **判定问题（Decision Problem）**：只有 yes/no 答案，如"是否存在比给定界更好的解？"；
  - **最优值/最优解（Optimal Value / Optimal Solution）**：求最优解的值 / 求达到最优值的一个解；
  - **数值计算（Numerical Calculation）**：关注精度等。
- **算法（Algorithm）**：用计算机解决问题的方法/过程；接收问题输入，将其转化为输出；一个问题可以有很多算法。
- **算法 vs 程序**：程序是给人读的之外给计算机读的；算法是给人读的，可用伪代码或简短步骤表达。程序是算法在某种编程语言下的一个具体实例（instance / concrete representation）。📌 *红字：**computer / human being**。*
- **算法设计的两个"冲突"目标**：
  1. 设计易于理解、编码、调试的算法；
  2. 设计高效利用计算机资源的算法。
  📌 *两条目标均红字。*

### 1.2 问题分类与复杂度类

- **计算复杂性（Computational Complexity）**：按解决问题所需最小资源（时间、空间等）对问题分类。重要的类：**P、NP、NPC、PSPACE、PTAS** 等。
  - **P**：存在多项式时间算法可求解；
  - **NP**：解可以在多项式时间内被**验证/检查**；
  - **NPC（NP-完全）**：可能不存在多项式算法的问题（实践中很多重要问题是 NPC 的）；
  - 关系：NP = P + NPC（若 P ≠ NP），核心问题 **P =? NP**。
  📌 *红字：NPC 的解 **may not** be **solved** in poly-time；NP 的解可在多项式时间被 **checked**。*
- **对付 NPC 问题的方法**：
  - **启发式算法（Heuristic）**：凭经验快速求解，但不保证正确性；
  - **近似算法（Approximation）**：多项式时间内给出接近最优的解；
  - **快速精确算法**：比朴素搜索快得多的有效指数时间算法；
  - **参数化算法（Parameterized）**：参数较小时高效。

  📌 *四类方法名全部红字强调。*

### 1.3 四个代表性问题（贯穿全课）

| 问题 | 输入 | 目标 | 复杂度 / 方法 |
|---|---|---|---|
| 区间调度（Interval Scheduling） | 任务集合，各带开始/结束时间 | 找最多的互不冲突（不重叠）任务 | n log n，**贪心** |
| 带权区间调度（Weighted Interval Scheduling） | 任务带开始/结束时间与权重 | 找权重和最大的相容子集 | n log n，**动态规划** |
| 独立集（Independent Set） | 图 | 找最大的互不相邻点集 | **NP-complete** |
| 竞争设施选址（Competitive Facility Location） | 点带权图，两人轮流选点（不能选已选点的邻居） | 选出最大权子集 | **PSPACE-complete**（博弈问题） |

> 结论：不同问题分属不同复杂度类——有的贪心即可、有的需要 DP、有的是 NP 难、有的甚至更难（PSPACE）。
>
> 📌 *红字：无权版目标 **maximum cardinality**、带权版目标 **maximum weight**（四个问题的目标词全标红）。*

## 2. 算法分析基础（Analysis）

### 2.1 运行时间的度量

- **最坏情况运行时间（Worst case）**：对给定规模 N 的输入，算法运行时间的最大可能界限。（📌 红字：**largest possible**）
- **平均情况运行时间（Average case）**：对随机输入的期望运行时间关于 N 的界限。（📌 红字：**random**）
- 不用"钟表"计时：希望有对所有实例统一的标准；运行时间/空间通常与输入规模相关。
- **暴力搜索（Brute force）**：很多非平凡问题天然存在检查所有可能解的穷举算法；最大独立集的暴力搜索需 **2^N** 时间（N 为顶点数）。（📌 红字：以 **Max independent set problem** 为例）
- **多项式 vs 指数（为什么重要）**：
  - 输入规模翻倍时，n³ 变为 8 倍（常数倍）；3ⁿ 变为 3ⁿ 倍（与 n 相关）；
  - 指数增长是恐怖的（国际象棋麦粒故事：2⁶⁴ ≈ 1.8×10¹⁹）；2¹⁰⁰ ≈ 1.27×10³⁰；
  - 应尽量避免指数运行时间；"是否每个问题都有多项式算法"是计算机科学的核心问题。

### 2.2 渐进分析（Asymptotic Order of Growth）

**核心思想：忽略常数因子与低阶项。** 100n²、1.5n²、n²+4、10n²−3n+6 都视为 Θ(n²)。

> 📌 **老师红字：渐进表式的核心内容就是忽略常数！**（等式中的渐近记号 = 其中的**某个函数**，此句亦红字）

设对所有 n 有 f(n) ≥ 0，g(n) ≥ 0：

| 记号 | 定义 | 直观含义 | 类比 |
|---|---|---|---|
| **O(g(n))** | ∃ c>0, n₀，∀n≥n₀：0 ≤ f(n) ≤ c·g(n) | 渐近上界 | a ≤ b |
| **Ω(g(n))** | ∃ c>0, n₀，∀n≥n₀：0 ≤ c·g(n) ≤ f(n) | 渐近下界 | a ≥ b |
| **Θ(g(n))** | ∃ c₁,c₂>0, n₀，∀n≥n₀：c₁g(n) ≤ f(n) ≤ c₂g(n) | 紧渐近界 | a = b |
| **o(g(n))** | ∀c>0，∃n₀，∀n≥n₀：0 ≤ f(n) < c·g(n)；等价 f(n)/g(n) → 0 | 非紧上界 | a < b |
| **ω(g(n))** | ∀c>0，∃n₀，∀n≥n₀：0 ≤ c·g(n) < f(n)；等价 f(n)/g(n) → ∞ | 非紧下界 | a > b |

- "f(n) = O(g(n))" 实指 f(n) **∈** O(g(n))，属于符号的滥用（习惯问题）。
- 例：f(n) = 32n² + 17n + 32 ∈ O(n²), O(n³), Ω(n²), Ω(n), Θ(n²)；∉ O(n), Ω(n³), Θ(n), Θ(n³)。
- 等式中的渐近记号表示"其中某个函数"：2n² + 3n + 1 = 2n² + Θ(n)。

**记号的性质**：

1. **传递性**：f = Θ(g), g = Θ(h) ⇒ f = Θ(h)（O、Ω、o、ω 同理）；
2. **自反性**：f = Θ(f), f = O(f), f = Ω(f)；
3. **对称性**：f = Θ(g) ⟺ g = Θ(f)；
4. **互对称（转置）**：f = O(g) ⟺ g = Ω(f)；f = o(g) ⟺ g = ω(f)；
5. **算术运算**：
   - O(f) + O(g) = O(max{f, g}) = O(f + g)；
   - O(f) · O(g) = O(f·g)；
   - O(c·f) = O(f)；
   - g = O(f) ⇒ O(f) + O(g) = O(f)。

**常用关系式**：

- **多项式**：a₀ + a₁n + … + a_d n^d = **Θ(n^d)**（a_d > 0）；
- **对数**：O(log_a n) = O(log_b n)（a,b > 1 为常数，底数不重要）；
- 对任意 x > 0：log n = **O(n^x)**（对数慢于任何多项式）；
- 对任意 r > 1 和 d > 0：n^d = **O(r^n)**（多项式慢于任何指数）。

### 2.3 三种算法设计技术总览

| 技术 | 核心思想 | 典型例子 |
|---|---|---|
| **贪心（Greedy）** | 每步做局部最优选择，希望导致全局最优；简单高效，但可能不最优 | 区间调度 O(n log n) |
| **分治（Divide & Conquer）** | 分解→递归求解→合并 | FFT O(n log n)、Karatsuba 乘法 |
| **动态规划（DP）** | 把问题分解为一系列**重叠子问题**，自底向上/记忆化求解 | 编辑距离 O(n²)、背包 |

- 设计模式 vs 反模式：
  - 模式：贪心、分治、DP、对偶性（bipartite matching O(n³)）、规约、局部搜索、随机化；
  - 反模式：NP-完全（不太可能有 O(n^c) 算法）、PSPACE-完全、不可判定（无算法）。
  📌 *红字：模式 **Reductions**、反模式 **NP-completeness**。*

## 3. 稳定匹配（Stable Matching）

### 3.1 问题定义

- 背景：n 个男性与 n 个女性，每人给出对异性的完整偏好排序；求一个"合适"的匹配。应用：医学院学生与医院的匹配（Nsmp 等）。
- **完美匹配（Perfect Matching）**：每人恰好匹配一人（一夫一妻）。
- **不稳定对（Unstable Pair）**：匹配 M 中，m-w 未配对但 m 与 w **互相**偏好对方胜过自己当前伴侣（两人有"私奔"动机）。📌 *红字出现 4 次——全章最核心的概念。*
- **稳定匹配（Stable Matching）**：没有不稳定对的完美匹配。
- **稳定匹配问题**：给定偏好表，求一个稳定匹配（若存在）。
- 注意：**稳定室友问题（Stable Roommate）**的稳定匹配可能不存在（存在无稳定匹配的实例：A-B,C-D ⟹ B-C 不稳定 等）。

### 3.2 Gale-Shapley 提议-拒绝算法（Propose-and-Reject, 1962）

> 📌 *红字：GS 算法对**任何（any）**问题实例都能保证找到稳定匹配。*

```text
初始化每个人为自由
while (存在某个男性 m 自由且未向所有女性提议过) {
    w = m 偏好列表中下一个尚未提议的女性
    if (w 自由)  m 与 w 订婚
    else if (w 更偏好 m 胜过未婚夫 m′) {
        m 与 w 订婚; m′ 恢复自由     // 女性"只升不降"
    } else  w 拒绝 m
}
```

**正确性证明**（三步）：

1. **终止性**：男性按偏好递减顺序提议；女性一旦订婚就不会再变回自由，只会"越换越好"（trade up）。每次 while 循环是一次新提议，最多 n² 次 ⟹ 算法最多 n² 次迭代终止（最坏情况需 n(n−1)+1 次提议）。
2. **完美性**（所有人被匹配）：反证。设 Zeus 未匹配，则由 n 男 = n 女，必有某女（Amy）也未匹配；由观察 2，Amy 从未被提议过；但未匹配的 Zeus 向所有人提议过，矛盾。
3. **稳定性**（无不稳定对）：反证。设 A-Z 不稳定：
   - 情形 1：Z 从未向 A 提议 ⟹ Z 更偏好其 GS 伴侣 ⟹ A-Z 稳定，矛盾；
   - 情形 2：Z 向 A 提议过 ⟹ A 拒绝过 Z ⟹ A 更偏好其 GS 伴侣 ⟹ A-Z 稳定，矛盾。∎

### 3.3 高效实现（O(n²)）

- 自由男性列表（队列/栈）；数组 wife[m]、husband[w]；
- 每个男性维护偏好列表与计数器 count[m]（已提议次数）；
- 每个女性预处理**逆偏好表** inverse（inverse[pref[i]] = i），使"是否偏好 m 胜过 m′"的判断 O(1)。📌 *红字。*

### 3.4 解的结构性质

> 📌 *红字关键词：**valid partner**（有效伴侣）、**man-optimal**（男性最优）、**woman-pessimal**（女性最差）。*

- 同一实例可能有**多个稳定匹配**；但 **Gale-Shapley 的所有执行结果相同**。
- **有效伴侣（Valid Partner）**：m 是 w 的有效伴侣，若存在某个稳定匹配使二者匹配。
- **男性最优（Man-Optimal）**：GS（男性提议版本）中每个男性都得到其**最好的有效伴侣**；且该指派本身是稳定匹配。
  - 证明思路：反证，设男性 Y 首次被某有效伴侣 A 拒绝；A 当时与更偏好的 Z 订婚；在 A-Y 匹配的稳定匹配 S 中，Z 尚未被任何有效伴侣拒绝过 ⟹ Z 偏好 A 胜过其 S 伴侣 B ⟹ A-Z 在 S 中不稳定，矛盾。（📌 红字："**first**"×2——取第一个被有效伴侣拒绝的男性是归纳证明的关键。）
- **女性最差（Woman-Pessimal）**：GS 得到的稳定匹配中，每个女性得到其**最差的有效伴侣**（男性最优的代价）。
- **扩展**：医院-居民匹配（部分人不可接受、男女数量不等、多配额"有限多夫制"）；不稳定定义相应扩展。

## 4. 贪心算法（Greedy）

### 4.1 基本思想

- 每次迭代选择**当前**看来"最好"的解；局部最优 ≠ 全局最优。
- 优点：简单、高效；缺点：可能不正确/不最优，需要证明。

### 4.2 区间调度（Interval Scheduling）

- 任务 j 从 s_j 开始到 f_j 结束；两任务相容 ⟺ 不重叠；目标：最大化相容任务数。
- **贪心模板：按某种顺序考虑任务，只要与已选任务相容就选。** 📌 *红字：**compatible**（相容）。*
- 四种看似合理的排序策略（前三者可被反例打破）：
  1. 最早开始时间 s_j —— ✗（长任务挡住后面许多任务）；
  2. **最早结束时间 f_j** —— ✓ **正确策略**；
  3. 最短区间 f_j − s_j —— ✗；
  4. 最少冲突数 c_j —— ✗。
- **正确贪心**：按结束时间递增考虑，相容即选。实现：按 f 排序，记住最后加入的任务 j*，任务 j 相容 ⟺ s_j ≥ f_{j*}；**O(n log n)**。
- **最优性证明（反证 + 交换思想，"greedy stays ahead"）**：设贪心选 i₁,…,i_k，最优解 j₁,…,j_m（m > k），取 r 最大使 i₁=j₁,…,i_r=j_r。则 f_{i_{r+1}} ≤ f_{j_{r+1}}（贪心选择的任务结束更早），用 i_{r+1} 替换 j_{r+1} 后解仍可行且大小不变，但公共前缀变长，与 r 的最大性矛盾。∎
- **贪心分析策略**：
  - **Greedy stays ahead**：证明每步之后贪心的解不劣于任何其他算法；
  - **交换论证（Exchange argument）**：逐步把最优解换成贪心解而不损失；
  - 其他经典贪心：Kruskal、Prim、Dijkstra、Huffman 等。

### 4.3 硬币找零（Coin Changing）

- 币值 {1, 5, 10, 25, 100}，付 x 元用最少硬币：每次加"不超过剩余金额的最大币值"硬币——对该币值系统贪心最优（这也是作业题）。
- **反例（非典型币值系统）**：US postal 币值 {1, 10, 21, 34, 70, 100, 350, 1225, 1500}：付 140¢，贪心 = 100+34+1×6（8 枚），最优 = 70+70（2 枚）。

### 4.4 补充课件中的贪心实例

- **0-1 背包的贪心不可行**：按单位重量价值 V_i/W_i 降序装——不是最优（存在反例，见作业/教材）。
- **最优装载（Optimal Loading）**：载重 c 的船装尽量多的集装箱（体积不限）——"最轻者先装"贪心得到最优解；证明可用交换论证/数学归纳法。
- **单源最短路 Dijkstra**（贪心）：
  - 集合 S："到源的最短距离已确定"的顶点；dist[] 记录当前最短特殊路径长度；（📌 整句红字：把从源到 u 且**中间只经过 S 中顶点**的路称为从源到 u 的**特殊路径**。）
  - 每次从 V−S 取 dist 最小的 u 加入 S，并松弛 dist；
  - 例：源为 1 的迭代表：初始 {1}: dist = [10, ∞, 30, 100] → 加入 2 → [10, 60, 30, 100] → 加入 4 → [10, 50, 30, 90] → 加入 3 → [10, 50, 30, 60] → 加入 5。
- **最小生成树（MST）**：
  - **MST 性质（切割性质）**：U ⊂ V，(u,v) 是横跨 U 与 V−U 的最小权边，则存在一棵包含 (u,v) 的 MST；
  - **Prim**：从 S={1} 出发，每次把横跨 S/V−S 的最小权边的端点 j 加入 S；用 closest[]、lowcost[] 数组实现，时间 O(n²)；
  - **Kruskal**：n 个孤立连通分支开始，边按权递增查看：两端点属不同分支则连接（并查集 + 优先队列/堆）；时间 O(e log e)；稀疏图（e ~ n）时优于 Prim 的 O(n²)，稠密图时较差。

### 4.5 supplement 中的其他贪心问题

- **区间划分（Interval Partitioning）**：n 个讲座安排到最少教室使无同室冲突。
  - **深度（depth）**：任一时刻同时进行的最大区间数；**下界：所需教室数 ≥ depth**；（📌 红字：**depth** 与例"a, b, c all contain 9:30"。）
  - 贪心：按**开始时间**递增，把讲座放入任一相容教室（优先队列维护各教室最后结束时间），O(n log n)；
  - **最优性**：设贪心开启第 d 间教室是为了安排讲座 j，它与之前 d−1 间教室都冲突；由于按开始时间排序，这 d 个讲座都在 s_j+ε 时刻重叠 ⟹ depth ≥ d ⟹ 贪心用了 d 间 = 下界，最优。∎
- **选择停靠点（Selecting Breakpoints）**：容量 C 的车走固定路线，加油点最少——"能开多远就多远"贪心最优（反证 + 与最优解逐点比较，greedy stays ahead）。
- **树上的独立集**：📌 *红字：根节点 **breaks the communication**（切断子树间通信）——树上问题可解的结构性原因。*
  - 关键观察：**若 v 是叶子，则存在包含 v 的最大独立集**（交换论证）；
  - 贪心算法（森林版）：每次取叶子端点加入 S 并删除 u、v 及关联边；O(n)（后序遍历）；
  - **带权版用 DP**：Optin(u)/Optout(u) = 以 u 为根的子树中 包含/不包含 u 的最大权独立集；
    - 叶子：Optin = w_u, Optout = 0；
    - 内点：Optin(u) = w_u + Σ_{v∈children(u)} Optout(v)；Optout(u) = Σ_{v∈children(u)} max(Optin(v), Optout(v))；
    - 答案 max(Optin(r), Optout(r))，O(n)。

## 5. 分治法（Divide and Conquer）

### 5.1 设计思想与一般步骤

- 将难以直接解决的大问题划分为规模较小的子问题，分别求解，再合并子问题的解。
- **求解过程：分—治—合**：
  1. **划分**：规模 n 的问题划分为 k 个规模较小的子问题，尽量均衡；
  2. **求解**：递归求解各子问题（解法与原问题相同）；
  3. **合并**：合并子问题的解（算法有效性很大程度依赖合并的实现）。
- 典型情形：2 个 n/2 子问题 + 线性合并 ⟹ T(n) = 2T(n/2) + O(n) = O(n log n)。📌 *红字：**two** 等长部分 + **linear time** 合并。*
- **注意：并非所有分治都优于蛮力**（例如计算 aⁿ 的分治若不合并子问题反而慢；要分析时间性能）。

### 5.2 排序问题

- **归并排序（Merge Sort）**：
  - 划分为等长两半 → 递归排序 → 合并两个有序序列（线性合并）；
  - T(n) = 2T(n/2) + O(n) ⟹ **O(n log₂ n)**；合并需辅助数组 ⟹ 空间 **O(n)**；
  - 伪代码：MergeSort(r, s, t)：s=t 返回；m=(s+t)/2 递归两半；Merge(r, r1, s, m, t)；回拷。Merge：双指针 i、j 比较取小者，收尾处理剩余。
- **快速排序（Quick Sort）**：
  - 选轴值（pivot），按**值**划分（归并按**位置**划分）：左边 ≤ 轴值 ≤ 右边；轴值位于最终位置；递归两侧；**合并不需要操作（就地）**；
  - 一次划分（以第一个记录为轴值）：i、j 双向扫描——右扫描找小于轴值的交换到前，左扫描找大于轴值的交换到后，直到 i=j 即轴值最终位置；（📌 课件红字标在划分示例的元素上——**掌握一次划分的手动模拟**。）
  - **最好/平均**：T(n) = 2T(n/2) + n ⟹ **O(n log₂ n)**（平均可用归纳法证明）；
  - **最坏**（正序/逆序输入）：n−1 次递归，第 i 趟比较 n−i 次 ⟹ **O(n²)**；
  - **空间**：就地划分 O(1)，递归栈最好 O(log n)、最坏 O(n)。

### 5.3 组合问题

- **最大子段和（Maximum Subsegment/Subarray Sum）**：
  - 序列 (a₁,…,a_n) 的最大 ∑_{k=i}^{j} a_k（全负时为 0）；例：(-20, 11, -4, 13, -5, -2) ⟹ 20（11−4+13）；
  - 分治：从中点划分，三种情况：① 完全在左（递归）②完全在右（递归）③**横跨中点**（左半从 mid 向左的最大和 s₁ + 右半从 mid+1 向右的最大和 s₂）；
  - 合并取 max{leftsum, s₁+s₂, rightsum}；T(n) = 2T(n/2) + O(n) ⟹ **O(n log₂ n)**。
- **循环赛日程安排（n = 2^k 选手）**：
  - 要求：每人与其他 n−1 人各赛一次、每人每天赛一次；n 行 n−1 列表；
  - 分治：2^k 选手的日程表由 2^(k−1) 选手的日程表决定（左上角拷贝到右下、右上角加 n/2 得左下……）；自底向上迭代；复杂度 **O(n²)**（填 2^k×2^k 表）。

### 5.4 几何问题

- **最近点对问题（Closest Pair）**：
  - 蛮力 O(n²)；一维排序后 O(n log n)；二维分治 O(n log n)；
  - 划分：取 x 坐标**中位数**的垂直线 x=m，平衡分成 S₁、S₂；
  - 递归求两侧最近距离 d₁、d₂，d = min(d₁, d₂)；若全局最近对跨越两侧，则两点到 x=m 的距离均 < d ⟹ 只需检查宽度 2d 的垂直带 P₁、P₂；
  - 对带内按 y 排序后，每个点只需检查 y 坐标在 [y−d, y+d] 内的点，**最坏不超过 6 个** ⟹ 合并 O(n)；
  - T(n) = 2T(n/2) + O(n) ⟹ **O(n log₂ n)**。
- 凸包问题（课件略）。

### 5.5 整数乘法（主课件）

- n 位整数加法 O(n)；乘法蛮力 **Θ(n²)**；
- 分治热身：4 个 n/2 位乘法 + 移位相加，仍 T(n) = 4T(n/2) + O(n) = O(n²)；
- **Karatsuba-Ofman (1962)**：3 个 n/2 位乘法 + 加减移位：T(n) = 3T(n/2) + O(n) ⟹ **O(n^1.585)**（递归树：每层 3^k 个规模 n/2^k 的子问题）。📌 *红字：只需 **three** 个 n/2 位乘法。*
- 矩阵乘法：蛮力 Θ(n³)（能否超越——Strassen 等，留作阅读）。

### 5.6 计数逆序（Counting Inversions，supplement）

- 相似性度量：两个排名间的逆序数（i < j 但 a_i > a_j）；蛮力 Θ(n²)；（📌 红字：**inverted**（逆序）定义、**Divide / Conquer / Combine** 三步、合并前提两半各自 **sorted**。）
- 分治：divide（O(1)）+ 递归数两半内部逆序（2T(n/2)）+ **合并时数蓝绿（跨半）逆序**：假设两半各自有序，在**归并过程中**计数（每 当右半元素先出 时累加其左侧剩余元素个数），归并 O(n)、计数 O(n)；
- Sort-and-Count(L)：递归返回 (逆序数, 有序表)，合并三量 r = r_A + r_B + r_跨；**O(n log n)**。
- （配套演示：demo-merge-invert。）

## 6. 动态规划（Dynamic Programming）

### 6.1 核心思想

- **重叠子问题（Overlapping Subproblems）**：递归算法反复重访同一子问题；**避免重复计算同一子问题**是 DP 的本质；
- 三种范式的对比：
  - 贪心：增量构造解，每步局部最优；
  - 分治：子问题**独立**，分而治之再合并；
  - DP：子问题**重叠**，建解从小到大的一系列子问题；
- 设计 DP 算法最重要的步骤：**找到一个把问题分解为众多重叠子问题的好方式**（写出正确的递归定义/最优子结构）。
- 实现方式：**记忆化（Memoization，自顶向下+缓存）** 或 **自底向上（Bottom-up）填表**。

### 6.2 带权区间调度（Weighted Interval Scheduling）

- 任务 j：开始 s_j、结束 f_j、权重 v_j；相容 = 不重叠；目标：最大权相容子集。
- 贪心在任意权值下会失败（一个 weight=999 的长任务 vs 许多 weight=1 任务）。
- 记号：按结束时间排序 f₁ ≤ f₂ ≤ … ≤ f_n；**p(j) = 最大的 i < j 使任务 i 与 j 相容**。（📌 红字关键词：**compatible**、**weight**。）
- **二选一递归结构（Binary Choice）**：OPT(j) = 只用任务 1..j 的最优解值：
  - 情形 1：OPT 选 j ⟹ 不能用 {p(j)+1, …, j−1}，OPT(j) = v_j + OPT(p(j))；
  - 情形 2：OPT 不选 j ⟹ OPT(j) = OPT(j−1)；
  - **OPT(j) = max{ v_j + OPT(p(j)), OPT(j−1) }**（最优子结构）。
- 暴力递归因冗余子问题呈指数（层叠实例的递归调用数呈 Fibonacci 增长）；
- 记忆化或自底向上 M[j] = max{v_j + M[p(j)], M[j−1]} ⟹ **O(n log n)**（排序 + 求 p；填表 O(n)）；回溯构造解：j 与 p(j) 比较 M 值决定是否选 j。

### 6.3 0-1 背包（Knapsack）

- n 物品，物品 i 重 w_i > 0、价值 v_i > 0；容量 W；最大化总价值。
- **贪心（按 v_i/w_i 最大比）不最优**：反例（W=11：物品 (1,1,18),(2,6,22),(3,6,28),(4,7,28)?——课件例子 {3,4} 价值 40，贪心 {5,2,1} 只有 35）。
- **失败的第一次尝试**：OPT(i) = 前 i 个物品的最优——选了物品 i 并不能立刻知道剩余容量 ⟹ 需要更多子问题（**加入新变量：容量**）。
- **正确递归**：OPT(i, w) = 用物品 1..i、容量限制 w 的最大价值：
  - 不选 i：OPT(i−1, w)；
  - 选 i：v_i + OPT(i−1, w − w_i)（w_i ≤ w）；
- 自底向上填 (n+1)×(W+1) 表：M[0,w]=0；M[i,w] = M[i−1,w] 若 w_i > w，否则 max{M[i−1,w], v_i + M[i−1, w−w_i]}；
- **运行时间 Θ(nW)**：**不是输入规模的多项式（W 是数值，二进制编码 log W 位）⟹ "伪多项式（Pseudo-polynomial）"**；背包判定版是 NP-完全的。
- 补充课件（另一表格式定义）：f_i(j) = 前 i 个物品、容量 j 的最大利润，同上递推，**O(Mn)**；示例：p=(3,4,8,5), w=(2,1,4,3), M=6 ⟹ 最大利润 12（物品 1、2、4）。（📌 红字：表中 **+p** = 选中物品 i 时利润加 p_i。）

### 6.4 补充课件：经典 DP 例子

- **最长公共子序列（LCS）**：
  - X = ⟨x₁,…,x_m⟩, Y = ⟨y₁,…,y_n⟩；子序列 = 按原序取子集（可不连续）；
  - 蛮力：枚举 X 的 2^m 个子序列检查 ⟹ Θ(n·2^m)；
  - 递归：c[i,j] = 0（i=0 或 j=0）；c[i−1,j−1]+1（x_i = y_j）；max{c[i−1,j], c[i,j−1]}（x_i ≠ y_j）；
  - 填 (m+1)×(n+1) 表 + 方向表 b[i,j] 回溯构造解；**Θ(mn)**；（📌 红字：**边界条件**——其中一个序列为空时长度为 0；表中红字 **+1** = 对角匹配时加 1。）
  - 例：X=⟨A,B,C,B,D,A,B⟩, Y=⟨B,D,C,A,B,A⟩ ⟹ LCS = ⟨B,C,B,A⟩ 或 ⟨B,D,A,B⟩，长 4。
- **最长公共子串（Longest Common Substring，要求连续）**：
  - dp[i][j] = dp[i−1][j−1]+1（x_i = y_j）；**0**（x_i ≠ y_j，子串不能跳过）；
  - 答案 = 表中最大值；时间 **O(mn)**、空间 O(mn)；
  - 例：X=⟨A,B,C,B,C,D,E⟩, Y=⟨B,B,C,B,C,E⟩ ⟹ ⟨B,C,B,C⟩ 长 4。
- **矩阵链乘法（Chained Matrix Multiplication）**：
  - M₁M₂…M_r（维度 d₀×d₁, …, d_{r−1}×d_r），求最少初等乘法次数；
  - C(i,j) = min cost of M_i…M_j；**C(i,j) = min_{i≤k<j} { C(i,k) + C(k+1,j) + d_{i−1}d_kd_j }**（k 为分割点）；
  - 按链长 d = 1..r−1 递增填表；子问题 O(r²) 个、每个 O(r) ⟹ **O(r³)**；记录分割点 k 可构造最优加括号方式。
- **多阶段图单源单汇最短路（Multistage Shortest Path）**：
  - m 列（阶段）× n 节点，边只存在于相邻阶段；
  - m(i,j) = 源 (0,1) 到 (i,j) 的最短路：m(i,j) = min_k { c(i−1,k,j) + m(i−1,k) }；（📌 红字：源 **source (0,1)** → 终点 **destination (m−1,1)** 的 **shortest path**。）
  - 记录前驱可回溯路径；**O(mn²)**（对比 Dijkstra 在 N=mn 节点图上 O(N²)）。
- **鸡蛋掉落（Egg Dropping / 扔鸡蛋）**：
  - N 个鸡蛋、K 层楼；存在临界层 F：≤F 不碎、>F 碎；最坏情况下保证找出 F 的最少实验次数；
  - 特例：1 个鸡蛋 ⟹ K 次（只能从低往高试）；K=1 ⟹ 1 次；N > K ⟹ EggDrop(N,K)=EggDrop(N−1,K)；
  - 从第 i 层扔：碎 ⟹ EggDrop(N−1, i−1)；不碎 ⟹ EggDrop(N, K−i)；（📌 红字：**Egg breaks / Egg didn't breaks** 两种分支——递推式的来源。）
  - **EggDrop(N,K) = min_{1≤i≤K} { 1 + max(EggDrop(N−1, i−1), EggDrop(N, K−i)) }**（max 最坏情况，min 最优策略）；
  - 重叠子问题：关键是（鸡蛋数, 剩余楼层数），如 [1,10] 层 2 蛋与 [11,20] 层 2 蛋等价；记忆化/填表求解；
  - 示例：3 蛋 7 层 ⟹ 3 次；2 蛋 7 层 ⟹ 4 次。

### 6.5 树上带权独立集（见 §4.5）与编辑距离

- 编辑距离（Edit Distance / Levenshtein）：两串间由替换/插入/删除转化的最少操作数；DP O(n²)（主课件作为 P 中问题例子提及）。

## 7. 递归式的求解（Recurrences）

- **递归式（Recurrence）**：用更小输入上的值描述函数的等式/不等式；分治/分支搜索算法总导致递归式（如归并：T(n) = 2T(n/2) + n）。（📌 红字整句：**branch-and-search（divide-and-conquer）**是解 **difficult** 问题精确/启发式算法的常用技术，**必然导致 recurrence**。）
- 技术性约定：可省略 floor/ceiling、忽略边界条件（n/2 未必是整数）。

### 7.1 代换法（Substitution Method）

1. 猜解的形式；2. 数学归纳法验证并定常数。（📌 两词均红字：**Guess** + **Verify**；例中红字警示 **important: same constant c!**——归纳必须用同一个常数。）
- 例：T(n) = 2T(n/2) + n，猜 T(n) = O(n lg n)：归纳证 T(n) ≤ cn lg n（c ≥ 1）。
- **好的猜测**：从相似递归式类推（T(n)=2T(n/2+10)+n）；先证松上下界再收紧（Ω(n)、O(n²) ⟹ 试 Θ(n lg n)）。
- **谬误证明警示**：T(n)=4T(n/2)+n，猜 O(n²)：归纳只能得 T(n) ≤ cn² + n，**不能**吸收 ⟹ 必须证严格形式；**修正：加强归纳假设**，减去低阶项：设 T(k) ≤ c₁k² − c₂k，则 T(n) ≤ c₁n² − c₂n − (c₂n − n) ≤ c₁n² − c₂n（c₂ ≥ 1）⟹ T(n) = O(n²)。（📌 红字：**WRONG!**、**subtracting some lower-order terms**。）
- **换元**：T(n) = 2T(√n) + lg n：令 m = lg n、S(m) = T(2^m) ⟹ S(m) = 2S(m/2) + m ⟹ S(m) = O(m lg m) = O(lg n · lg lg n)。

### 7.2 迭代法 / 递归树（Iteration / Recursion Tree）

- 直接展开（代数）：T(n)=2T(n/2)+n = 4T(n/4)+2n = … = nT(1) + n log₂n；
- 递归树（几何）：例 T(n) = 3T(n/4) + Θ(n²)：
  - 第 k 层：3^k 个规模 n/4^k 的子问题，每节点代价 c(n/4^k)²，每层合计 (3/16)^k·cn²；
  - 层数 log₄n + 1；叶子 3^{log₄n} = n^{log₄3} 个，各 Θ(1)；
  - 几何级数求和 ⟹ **T(n) = Θ(n²)**（可用代换法验证）。

### 7.3 主方法（Master Method）

T(n) = aT(n/b) + f(n)，比较 f(n) 与 n^{log_b a}：

1. **情形 1**：f(n) = O(n^{log_b a − ε})（多项式地小）⟹ T(n) = **Θ(n^{log_b a})**；
2. **情形 2**：f(n) = Θ(n^{log_b a}) ⟹ T(n) = **Θ(n^{log_b a} · lg n)**；
3. **情形 3**：f(n) = Ω(n^{log_b a + ε}) 且正则条件 a·f(n/b) ≤ c·f(n)（c<1）⟹ T(n) = **Θ(f(n))**。

例：
- T(n) = 9T(n/3) + n：a=9,b=3, n^{log₃9}=n²，f(n)=n 多项式小 ⟹ Θ(n²)；
- T(n) = T(2n/3) + 1：a=1, b=3/2 ⟹ Θ(lg n)；
- T(n) = 2T(n/2) + n lg n：**主定理不适用**（f(n) 比 n^{log_b a}=n 大，但非多项式地大）。
- 局限：三情形未覆盖所有 f(n)（不是多项式地大/小的情况）。
- 📌 *红字：**Case 1 / Case 2 / Case 3** 三个情形名；例 T(n)=2T(n/2)+nlgn 处红字 **cannot use this theorem!**（要会识别主定理不适用的场合）。*

## 8. 最大流与最小割（Max Flow / Min Cut）

### 8.1 流网络（Flow Network）

- 抽象：物质沿边流动；G = (V, E) 有向图（无平行边）；**源 s、汇 t**；每边容量 c(e)。（📌 红字定义词：**flowing**；下文 **s-t cut / capacity**、**s-t flow / value** 均为红字强调。）
- 应用：数据挖掘、露天采矿、项目选择、航班调度、**二部图匹配**、棒球淘汰、图像分割、网络连通性/可靠性、分布式计算、稳定匹配、统计数据安全、网络入侵检测、多相机场景重建等。
- **s-t 割（cut）**：V 的划分 (A, B)，s ∈ A、t ∈ B；
  - **割容量** cap(A, B) = Σ_{e out of A} c(e)（只算 A→B 方向的边）；
  - **最小 s-t 割问题**：找容量最小的割。
- **s-t 流（flow）**：满足
  - **容量限制**：对每条 e ∈ E，0 ≤ f(e) ≤ c(e)；
  - **守恒律（conservation）**：对每个 v ∈ V − {s, t}，流入 = 流出；
  - **流值** v(f) = 离开源的净流量 = 进入汇的净流量；
  - **最大流问题**：找流值最大的 s-t 流。
- 例（课件标准图）：最大流值 = 28 = 最小割容量。

### 8.2 流与割的关键引理

- **流值引理（Flow value lemma）**：对任意流 f 与任意割 (A, B)，**跨割的净流量 = v(f)**（= 流出 s 的量）；
  - 证明：v(f) = Σ_{v∈A} (流出v − 流入v)，由守恒律除 s 外全部为 0。
- **弱对偶（Weak duality）**：对任意流 f 和任意割 (A, B)：**v(f) ≤ cap(A, B)**；
  - 证明：v(f) = 跨割净流量 ≤ Σ_{e out of A} f(e) ≤ Σ_{e out of A} c(e) = cap(A,B)。
- **最优性证书（Certificate of optimality）**：若某流 f 与某割 (A,B) 满足 v(f) = cap(A,B)，则 f 是最大流且 (A,B) 是最小割。

### 8.3 Ford-Fulkerson 算法

- **朴素贪心为何失败**：只沿"还有剩余容量"的 s-t 路径增广并贪心到底，会卡在非最优流（局部最优 ≠ 全局最优；例：贪心得 20，最优 30）。（📌 红字：**stuck**。）
- **残量网络（Residual Graph）**：
  - 原边 e = (u,v) 上流量 f(e)、容量 c(e)；
  - **残量边**：正向 e 的残量容量 c_e(f) = c(e) − f(e)（"还能加"）；**反向边 e^R = (v,u)** 的残量容量 f(e)（"撤销已送的流"）；
  - G_f = (V, E_f)：E_f = { e : f(e) < c(e) } ∪ { e^R : f(e) > 0 }。
- **增广路算法（Augmenting Path / Ford-Fulkerson）**：

```text
Ford-Fulkerson(G, s, t, c):
    对每条边 e: f(e) ← 0
    Gf ← 残量网络
    while (存在增广路 P —— Gf 中一条 s→t 路径):
        b ← bottleneck(P)  = P 上最小的残量容量
        对 P 上每条边 e:
            若 e 是前向边: f(e) += b
            若 e 是反向边: f(e^R) -= b
        更新 Gf
    return f
```

- **运行时间（整数容量 1..C）**：
  - 不变量：整个算法过程中所有流量与残量容量保持**整数**；
  - 每次增广至少使流值 +1 ⟹ 增广次数 ≤ v(f*) ≤ **mC**（m 为边数）；（📌 红字：运行 **time** 分析是强调点。）
  - C=1 时 O(m²)；
  - **整值定理（Integrality theorem）**：整数容量下存在每边流量均为整数的最大流（算法终止即证）。

### 8.4 最大流最小割定理（Max-Flow Min-Cut Theorem）

- **增广路定理**：流 f 是最大流 ⟺ **不存在关于 f 的增广路**。
- **最大流最小割定理** [Elias-Feinstein-Shannon 1956; Ford-Fulkerson 1956]：**最大流的值 = 最小割的容量**。
- 证明：同时证三个命题 (i) 存在割 (A,B) 使 v(f) = cap(A,B)；(ii) f 是最大流；(iii) 无增广路。
  - (i) ⇒ (ii)：弱对偶引理推论；
  - (ii) ⇒ (iii)（逆否）：若有增广路则可增流；
  - (iii) ⇒ (i)：令 A = 残量网络中从 s 可达的点集，则 s ∈ A、t ∉ A；(A,B) 是割；A→B 的边都饱和（f(e)=c(e)）、B→A 的边流量为 0 ⟹ v(f) = cap(A,B)。∎

### 8.5 运行时间的改进（选择好的增广路）

- **通用 FF 不保证多项式**：容量上限 C 时可能需要 C 次迭代（1、2 中间夹容量 C 的边，交替走 1 和 C−1 增广——2C 次增广；输入规模是 m, n, log C ⟹ 关于输入是**指数**的）；
- 容量为**无理数**时甚至不保证终止！
- 好的增广路选择 [Edmonds-Karp 1972, Dinitz 1970]：
  - 瓶颈容量最大的路；
  - 瓶颈容量足够大的路（**容量缩放**）；（📌 红字：**Sufficiently large bottleneck capacity**。）
  - 边数最少的路（最短增广路）。
- **容量缩放（Capacity Scaling）**：
  - 维护缩放参数 Δ；G_f(Δ) = 残量网络中残量容量 ≥ Δ 的边构成的子图；
  - 外层：Δ 初始化为 ≥ C 的最小 2 的幂；在 G_f(Δ) 中不断增广直到无增广路；Δ ← Δ/2；直到 Δ = 1；
  - **正确性**：整值不变量 ⟹ Δ=1 时 G_f(Δ) = G_f，终止时无增广路 ⟹ 最大流；
  - **时间**：外层 1 + ⌈log₂C⌉ 轮；每轮内层至多 2m 次增广（ lemma：每轮至多 m 次？课件：inner while ≤ 2m 次 ⟹ 总增广 **O(m log C)** 次，可实现 **O(m² log C)** 时间。
- **多终点流与多割（Multiflow/Multicut）**（思考题）：终端数 > 2 时，最大流值是否仍等于最小割值？两对终端 (s,t) 呢？（一般不成立。）

## 9. NP 与计算不可解性（NP-Completeness）

### 9.1 按计算需求分类问题

- **可行的工作定义** [Edmonds 1965 等]：有多项式时间算法的问题才是"实际可解"的。
- 难易对照（每对左易右难）：

| 易（P） | 难（NP-complete 等） |
|---|---|
| 最短路 Shortest Path | 最长路 Longest Path |
| 最小割 Min Cut | 最大割 Max Cut |
| 2-SAT | 3-SAT |
| 二部图匹配 Matching | 3D-匹配 3D-Matching |
| 平面图 4-着色 | 平面图 3-着色 |
| 二部图顶点覆盖 | 一般图顶点覆盖 Vertex Cover |

- 现状：大量基本问题几十年来无法确定归类；本章目标：证明这些问题**"计算等价"**——它们是同一个难问题的不同表现。（📌 红字：这些问题 are **really hard**。）

### 9.2 多项式时间规约（Polynomial-Time Reduction）

- **定义**：问题 X **多项式规约**到问题 Y（记 **X ≤_P Y**），若任意 X 的实例可解，仅使用：
  1. 多项式次标准计算步骤 + 2. 多项式次求解 Y 的**神谕（oracle）**调用。
  - （Cook 规约 = 多项式时间 Turing 规约；Karp 规约 = 多项式多一规约/变换 = 只在最后调用一次神谕。📌 红字：**polynomial reduces** 与 **polynomial transforms** 两个术语要区分。）
- **用途**：
  - **分类相对难度**；（📌 红字：按 **relative** difficulty 分类。）
  - **设计算法**：X ≤_P Y 且 Y 有多项式算法 ⟹ X 也有（代价是规约开销）；
  - **建立难解性**：X ≤_P Y 且 X 无多项式算法 ⟹ Y 也无；
  - **等价**：X ≤_P Y 且 Y ≤_P X 记 X ≡_P Y。
- **传递性**：X ≤_P Y 且 Y ≤_P Z ⟹ X ≤_P Z（组合两个算法）。
- **三种基本规约策略**：
  1. **简单等价（Simple equivalence）**；
  2. **特例到一般（Special case to general）**；
  3. **小配件编码（Gadgets）**。

  📌 *三种策略名称全部红字——复习时按这三类各记一组例子（对应 §9.3 的三个规约）。*

### 9.3 基本规约例子

- **独立集（INDEPENDENT-SET）**：给定 (G, k)，是否存在 |S| ≥ k 的点集 S 使每条边至多一个端点在 S 中？应用：找互不冲突的点集。
- **顶点覆盖（VERTEX-COVER）**：给定 (G, k)，是否存在 |S| ≤ k 的点集 S 使每条边至少一个端点在 S 中？（玩具应用：美术馆警卫问题。）
- **规约 1（简单等价）**：VERTEX-COVER ≡_P INDEPENDENT-SET。
  - **S 是独立集 ⟺ V − S 是顶点覆盖**：
    - (⇒) S 独立 ⟹ 任意边 (u,v) 至少一端不在 S ⟹ 被 V−S 覆盖；
    - (⇐) V−S 是覆盖 ⟹ S 内任意两点无边相连 ⟹ S 独立。∎
- **规约 2（特例到一般）**：VERTEX-COVER ≤_P SET-COVER。
  - **集合覆盖（SET-COVER）**：全集 U、子集族 S₁,…,S_m、整数 k，是否存在 ≤ k 个子集其并等于 U？（应用：用最少的软件包覆盖全部 n 项功能。）
  - 构造：U = E（边集），对每个顶点 v 建 S_v = 与 v 关联的边集，k 不变 ⟹ 顶点覆盖 size ≤ k ⟺ 集合覆盖 size ≤ k。∎
- **规约 3（gadgets）**：3-SAT ≤_P INDEPENDENT-SET。
  - **SAT/3-SAT**：文字 = 变量或其否定；子句 = 文字的析取；CNF = 子句的合取；SAT 问 CNF 是否有成真赋值；3-SAT 每子句恰 3 个文字（任意逻辑公式都可化为 CNF）；
  - 构造：每个子句 3 个文字建 3 个顶点并**连三角形**；每个文字与其**否定**连边；k = 子句数；
  - (⇒) 大小 k 的独立集必须每三角形恰取一点 ⟹ 取的文字设真 ⟹ 一致且满足所有子句；
  - (⇐) 成真赋值下每三角形取一个真文字 ⟹ 独立集。∎
- 规约链：3-SAT ≤_P IND-SET ≤_P VERTEX-COVER ≤_P SET-COVER（传递性）。

### 9.4 自可规约性（Self-Reducibility）

- 判定问题（是否存在 size ≤ k 的顶点覆盖？）vs 搜索问题（找最小顶点覆盖）。（📌 红字：判定问 **exist**、搜索问 **Find**。）
- **自可规约性：搜索问题 ≤_P 判定版本**（本章所有 NP-完全问题均如此）——**这为只研究判定问题的合理性辩护**。
- 例（找最小顶点覆盖）：二分搜索最小基数 k*；找顶点 v 使 G − {v} 有 size ≤ k*−1 的覆盖（任一最小覆盖中的顶点都有此性质）；把 v 放入解，递归 G − {v}。

### 9.5 P、NP、EXP

- **判定问题形式化**：问题 X 是字符串集合；算法 A 解决 X ⟺ A(s)=yes ⟺ s ∈ X；**多项式时间**：A(s) 在 p(|s|) 步内终止。
- **P**：存在多项式时间算法的判定问题。例：MULTIPLE（除法）、RELPRIME（欧几里得）、PRIMES（AKS 2002）、EDIT-DISTANCE（DP）、LSOLVE（高斯消元）。
- **证书/认证算法（Certifier / Certificate）**：
  - 认证算法 C(s,t)：**s ∈ X ⟺ ∃t（"证书/证据/witness"，|t| ≤ p(|s|)）使 C(s,t) = yes**；认证者从"管理者"视角检查给定的证据；
  - **NP = 存在多项式时间认证算法的判定问题**（NP = nondeterministic polynomial time）。📌 *红字：**certifier**、**poly-time**、**nondeterministic**；P 的 **poly-time algorithm** 与 EXP 的 **exponential-time algorithm** 亦红字（三者定义对记忆）。*
  - 例：COMPOSITES（证书：非平凡因子 t，541×809=437,669）；SAT（证书：赋值）；HAM-CYCLE（证书：点的排列）。
- **EXP**：存在指数时间算法的判定问题。
- **包含关系**：P ⊆ NP ⊆ EXP。
  - P ⊆ NP：证书 t = ε（空串），认证器就是算法本身；
  - NP ⊆ EXP：枚举所有 |t| ≤ p(|s|) 的证书 t 跑 C(s,t)（指数多个）。
- **主问题 P vs NP** [Cook 1971, Levin, …]：判定问题是否与认证问题一样容易？Clay 千禧年百万美元奖。
  - 若 P=NP：3-COLOR、TSP、因子分解、SAT 等都有高效算法（**RSA 密码学崩溃**）；
  - 共识：**大概率 P ≠ NP**。

### 9.6 NP-完全（NP-Complete）

- **多项式变换（Karp）**：给定 x ∈ X 的任意输入，构造输入 y，使 x 是 yes ⟺ y 是 yes（|y| 关于 |x| 多项式）。
- **NP-完全定义**：Y ∈ NP 且对**每个** X ∈ NP 有 X ≤_p Y（NP 中"最难"的问题）。
- **定理**：Y 是 NP-完全的 ⟹ Y 可多项式求解 ⟺ P = NP。
- **第一个 NP-完全问题**：**CIRCUIT-SAT**（组合电路可满足性）[Cook 1971, Levin 1973]：
  - 任何固定输入位数的 yes/no 算法可表示为（多项式规模的）电路；
  - 对 X ∈ NP 的认证器 C(s,t)：把 s 硬编码进电路 K 的前 |s| 位，其余 p(|s)| 位代表 t；K 可满足 ⟺ ∃t 使 C(s,t)=yes。
- **证明 NP-完全的配方（Recipe）**：
  - **Step 1. 证明 Y ∈ NP**（给出多项式证书与认证器）；
  - **Step 2. 选一个已知的 NP-完全问题 X**；
  - **Step 3. 证明 X ≤_P Y**。
  - 依据（推论）：X NP-完全、Y ∈ NP、X ≤_P Y ⟹ Y NP-完全（对任意 W ∈ NP：W ≤_P X ≤_P Y）。
- **NP-完全问题的传播**：一旦确立第一个自然 NP-完全问题，其他问题如多米诺骨牌倒下（Karp 1972 分析了离散数学中最有意义的一批开放问题，证明多数 NP-完全；1985 图灵奖）。
- NP-完全问题的**六大类（genres）**：

| 类型 | 代表问题 |
|---|---|
| 装填 Packing | SET-PACKING、INDEPENDENT SET |
| 覆盖 Covering | SET-COVER、VERTEX-COVER |
| 约束满足 Constraint satisfaction | SAT、3-SAT |
| 排序/序列 Sequencing | HAMILTONIAN-CYCLE、TSP |
| 划分 Partitioning | 3D-MATCHING、3-COLOR |
| 数值 Numerical | SUBSET-SUM、KNAPSACK |

> 📌 *红字强调的三大类：**Sequencing problems**、**Partitioning problems**、**Numerical problems**——恰好对应作业三、四的规约证明题方向。*

- 实践：多数 NP 问题要么已知属于 P，要么 NP-完全；**著名例外**：因子分解（Factoring）、图同构（Graph Isomorphism）、纳什均衡（Nash equilibrium）。
- NP-完全性的影响 [Papadimitriou 1995]：CS 向其他学科最重要的智力输出；每年 6000+ 引用；应用遍及航空工程（有限元网格划分）、生物（蛋白质折叠）、化学工程、土木（交通流平衡）、经济（套利计算）、电气（VLSI 布局）、金融（最小风险组合）、博弈论（纳什均衡）、基因组（系统发生重建）、物理（3D Ising 模型配分函数）、扫雷（Minesweeper consistency）等。

### 9.7 各类 NP-完全性证明（Sequencing / Partitioning / Numerical）

- **DIR-HAM-CYCLE ≤_P HAM-CYCLE**：每个点 v 拆成三点（v_in, v_mid, v_out）的链式 gadget，G' 有 3n 个点；有向哈密顿圈 ⟺ 无向哈密顿圈（圈在 gadget 中只能以两种一致顺序穿过）。（📌 红字：输入是 **digraph** 有向图。）
- **3-SAT ≤_P DIR-HAM-CYCLE**：
  - 构造 2ⁿ 条哈密顿圈对应 2ⁿ 个真赋值（第 i 行从左到右 ⟺ x_i = 1；行间有转移边）；
  - 每个子句 C_j 加一个**子句节点**与 6 条边：只有当对应行以"正确方向"经过时才能把 C_j 拼接进圈；
  - (⇒) 成真赋值按方向走行，每个子句至少一行方向正确可拼入；
  - (⇐) 圈经过 C_j 必须走"mate edge"，删除所有子句节点得圈 ⟹ 定义赋值 x_i* = 1 ⟺ 圈从左到右走第 i 行；每个子句节点被访问 ⟹ 至少一行方向正确 ⟹ 子句满足。∎
- **LONGEST-PATH**（有向图长 ≥ k 的简单路径？）NP-完全：3-SAT ≤_P LONGEST-PATH（同上构造去掉 t→s 回边），或 HAM-CYCLE ≤_P LONGEST-PATH（问长 ≥ n−1 的路径）。（📌 红字：LONGEST 是 **at least k**、SHORTEST 是 **at most k**——两词均标红。）
  - 注意：把边权取负求最短路的方法**不适用**（负权回路 + 简单路径约束）。
- **TSP**（n 城市、距离函数 d、问长 ≤ D 的巡回？）：HAM-CYCLE ≤_P TSP——G 中边权 1、非边权 2，问长 ≤ n 的巡回 ⟺ G 有哈密顿圈。
- **3D-MATCHING**（X, Y, Z 各 n 元素、三元组集 T ⊆ X×Y×Z，问是否存在 n 个三元组使每个元素恰属其一；教师-课程-时间分配）：3-SAT ≤_P 3D-MATCHING——每个变量建 gadget（2k core + 2k tip 元素，必须成对选灰或选蓝 ⟺ 赋真/假），每个子句 2 元素 3 三元组（恰可用其一 ⟹ 至少一个对应文字的 core 被"解放"），tip 配 cleanup gadget。
- **3-COLOR**（能否用红绿蓝 3 色染点使相邻异色；应用：**寄存器分配** [Chaitin 1982]——干涉图 k-可着色 ⟺ 可分配 k 个寄存器；3-COLOR ≤_P k-REGISTER-ALLOCATION, k ≥ 3）：3-SAT ≤_P 3-COLOR：
  - 每个文字一个点；**T-F-B 三角**，每个文字连 B；文字与其否定连边；每个子句加 6 点 13 边 gadget；
  - (⇒) 3-着色 ⟹ 每文字 T 或 F、文字与否定异色、子句 gadget 全红则不可着色 ⟹ 每子句至少一文字 T ⟹ 成真赋值；
  - (⇐) 成真赋值 ⟹ 真文字染 T、假染 F、中间行染 B、其余强制。∎
- **SUBSET-SUM**（自然数 w₁,…,w_n 与 W，问是否有子集恰加出 W；注意整数按二进制编码）：3-SAT ≤_P 3D-MATCHING ≤_P SUBSET-SUM（书上的构造：每个三元组建 3n 位（m+1 进制）整数，位 i、n+j、2n+k 置 1；问能否加出 111…111）。（📌 红字：**binary**——二进制编码是伪多项式 vs NP-完全辨析的关键。）
- **SCHEDULE-RELEASE-TIMES**（n 个任务带时长 t_i、释放 r_i、截止 d_i，单机连续调度？）：SUBSET-SUM ≤_P 它：任务 t_i=w_i、r_i=0、无截止；加任务 0（t=1, r=W, d=W+1）卡住 [W, W+1] ⟹ 可行 ⟺ 有子集和恰为 W。
- **PARTITION**（能否分成和相等的两半）：SUBSET-SUM ≤_P PARTITION——加两个数 2Σw−W 与 Σw+W（二者不能同侧）。
- **平面图 3-着色（PLANAR-3-COLOR）**：3-COLOR ≤_P PLANAR-3-COLOR：
  - 平面图：可嵌入平面使边不交叉（Kuratowski：非平面 ⟺ 含与 K₅ 或 K₃,₃ 同胚的子图；平面性判定 [Hopcroft-Tarjan 1974] O(n)）；（📌 红字：**planar**。）
  - 交叉 gadget W：任何 3-着色中对角同色；对角同色的颜色可延拓；把每处边交叉替换为 W。∎
  - 注意：平面图 4-着色属于 P（四色定理），3-着色 NP-完全。

### 9.8 补充 PDF：图规约小结（Clique 等）

- **k-Clique**：图中是否有 k-团；**Vertex Cover**：点覆盖。
- **Clique ≤_p Vertex Cover**：取**补图** Ḡ，k′ = n − k；(G,k) 是 yes ⟺ G 有 k-团 ⟺ Ḡ 有 size n−k 的点覆盖（团内点在补图中无边 ⟹ 其余 n−k 点覆盖所有边，反之亦然）。
- **HAM-CYCLE ≤_p TSP**：完全图上原有边权 1、其余权 2，阈值 k = N ⟺ 权 N 巡回 ⟺ 哈密顿圈。
- **HAM-CYCLE ≤_p Longest Path**：任取 s，新建 t，对每条 (u, s) 加 (u, t)，k = N ⟺ 长 k 路径 ⟺ 哈密顿圈。
- NP-完全的意义：一类问题**相互等价**——解其一则解全部；证明其一无高效算法则全体无。
- **应对 NP-完全性**：① 平均情形快的算法（但有些问题连平均也难）；② 近优解（近似算法；但有些问题连近似都 NP-难）；③ 尽量压低指数（SAT 的好指数算法实践可解 1000+ 输入的电路；但 2^{n/100} 终究指数）。

## 10. 近似算法（Approximation Algorithms）

### 10.1 为什么与是什么

- NP-难问题需要多项式算法时，必须在三个"理想特性"中牺牲一个：
  1. 最优求解；2. 多项式时间；3. 任意实例。
- **ρ-近似算法（ρ-approximation）**：保证 ① 多项式时间运行；② 求解任意实例；③ 解值与真最优值之比在 ρ 以内。
- 挑战：**在不知道最优值的情况下证明解接近最优**（需要下界技术）。（📌 红字：**Challenge**。）

### 10.2 性能指标（补充课件）

- 最优值 c*，近似解值 c：
  - **性能比（performance ratio）** ρ(n) = max{ c/c*, c*/c }（min 与 max 问题通用定义）；
  - **相对误差（relative error）** = |c − c*| / c*；
  - **相对误差界 ε(n)**：|c−c*|/c* ≤ ε(n)；关系 **ε(n) ≤ ρ(n) − 1**。
- **近似方案（Approximation Scheme）**：对任意固定 ε > 0 给出 (1+ε)-近似算法；
  - **PTAS**：时间关于输入规模 n 多项式（可含 1/ε 的高次，如 O(n²/ε)）；
  - **FPTAS**：时间关于 n **和** 1/ε 都多项式（如 O(n³/ε²)）——时间与解质量可权衡。

### 10.3 负载均衡 / 负载分配（Load Balancing，5.1）

- 输入：m 台同型机器、n 个任务（任务 j 处理时长 t_j，必须连续执行）；机器 i 的负载 L_i = Σ_{j∈J(i)} t_j；**makespan** L = max_i L_i；目标：最小化 makespan。（📌 红字：**load** 与 **makespan** 两个定义词。）
- **列表调度（List-Scheduling）[Graham 1966]**：按给定顺序逐个把任务放到**当前负载最小**的机器；优先队列实现 **O(n log m)**。
- **2-近似证明**：
  - **下界 1**：L* ≥ max_j t_j（最长任务总得有人做）；
  - **下界 2**：L* ≥ (1/m)·Σ_j t_j（某台机器至少干 1/m 的活）；
  - 设瓶颈机器 i 的负载 L = L_i，j 为 i 上**最后**安排的任务；分配 j 时 i 负载最小 ⟹ L_i − t_j ≤ L_k ∀k ⟹ m(L_i − t_j) ≤ Σ_k L_k ≤ Σ_j t_j ⟹ L_i ≤ t_j + Σt_j/m ≤ L* + L* = **2L***。∎
  - 这是**第一个最坏情况近似分析**（1966）。
- **紧性**：m 台机器、m(m−1) 个长 1 任务 + 1 个长 m 任务：列表调度 makespan = 2m−1，最优 = m ⟹ 比值 → 2，分析本质紧。
- **LPT 规则（Longest Processing Time first）**：任务按时长**降序**后再列表调度。（📌 红字：先 **Sort**。）
  - 观察：任务数 ≤ m 时列表调度即最优（每机一任务）；
  - **引理 3**：任务数 > m 时 L* ≥ 2·t_{m+1}（前 m+1 个任务每个 ≥ t_{m+1}，鸽笼原理某机至少 2 个）；
  - **定理**：LPT 是 **3/2-近似**（同样证法，代入 t_{m+1} ≤ L*/2）；
  - 3/2 分析不紧：[Graham 1969] 实际是 **4/3-近似**（更精细分析；紧例：2m−1 个任务）。

### 10.4 中心选址（Center Selection，5.2）

- 输入：n 个站点 s₁,…,s_n 与整数 k；选 k 个中心 C 最小化**覆盖半径** r(C) = max_i dist(s_i, C)；距离满足恒等、对称、**三角不等式**。平面欧氏版本中心可在任意点 ⟹ 搜索空间无限！
- **失败的贪心**：先把第一个中心放在单中心最优位置再逐步最大降幅——反例存在。
- **正确贪心**：每轮选**距现有中心最远的站点**作为新中心（中心只能设在站点上）。（📌 红字：**farthest**。）
  - 观察：终止时 C 中各中心两两相距 ≥ r(C)。
- **2-近似证明**（反证）：设 r(C*) < ½r(C)；C* 的每个中心落在某个以 c_i ∈ C 为心、半径 ½r(C) 的球内 ⟹ 一一配对；任意站点 s：dist(s, C) ≤ dist(s, c_i) ≤ dist(s, c_i*) + dist(c_i*, c_i) ≤ r(C*) + 2·½r(C)…… ⟹ r(C) ≤ 2r(C*)。∎
- **最优性界**：除非 **P = NP**，不存在 ρ < 2 的近似（任何 ρ < 2-近似算法都不存在）⟹ 此贪心（虽只允许中心在站点上）已是渐近最优。

### 10.5 定价法：（带权）顶点覆盖（Pricing Method，5.3）

- **带权顶点覆盖**：点带权 w_i ≥ 0，找覆盖所有边的最小权点集。
- **定价（pricing）思想**：每条边 e=(i,j) 支付费 p_e ≥ 0 以使用其端点；**公平性（fairness）**：与 i 关联的边付费总和 ≤ w_i。
- **公平价格引理**：对任意顶点覆盖 S 与任意公平价格：Σ_e p_e ≤ w(S)（对 S 中各点的公平不等式求和，每条边至少被 S 中一点覆盖故不重复计算）。
- **算法**：价格从 0 开始；只要存在边 i-j 两端点都"不紧"（tight：所关联边付费和 < w_i），选这样的边把 p_e 提高到恰好使一端变紧；结束取 S = 全部紧点。
- **2-近似证明**：算法终止（每轮至少一个新点变紧）；S 是覆盖（否则有边两端不紧，循环不会停）；w(S) = Σ_{i∈S} w_i = Σ_{i∈S} Σ_{e∋i} p_e ≤ Σ_e 2p_e（每边至多两端在 S）= 2Σ_e p_e ≤ 2w(S*)。∎

### 10.6 LP 舍入：带权顶点覆盖（LP Rounding，5.4）

- **整数规划（IP）形式**：0/1 变量 x_i（是否取点 i）；min Σ w_i x_i s.t. x_i + x_j ≥ 1（每条边）、x_i ∈ {0,1}；顶点覆盖 ⟺ IP，故 **INTEGER-PROGRAMMING 是 NP-难的**（即使系数 0/1、每条不等式至多两个变量）。
- **线性规划（LP）**：允许 x_i 为实数（去掉 0/1 约束）；单纯形 [Dantzig 1947] 实践高效；椭球法 [Khachian 1979] 多项式时间；LP 可行域是多面体（2D 中 = 直线围成的凸区域）。（📌 红字：LP 输出 **real numbers**，再 **round** 舍入。）
- **LP 松弛**：LP 最优值 ≤ ILP 最优值（约束更少）；但 LP 解不再是顶点覆盖 ⟹ **舍入（rounding）**。
- **½-舍入定理**：x* 为 LP 最优解，S = { i : x_i* ≥ ½ } 是顶点覆盖且 w(S) ≤ 2·OPT：
  - 覆盖性：x_i + x_j ≥ 1 ⟹ 二者至少一个 ≥ ½；
  - 权值界：w(S) = Σ_{i∈S} w_i ≤ Σ_i 2w_i x_i* = 2·LP* ≤ 2·OPT。∎
- **已知界**：[Dinur-Safra 2001] 若 P ≠ NP，ρ < 1.3607 不可能（即使单位权）；**2 与 1.3607 之间的空隙是开放问题**。（📌 红字：**7/6**（Håstad）与 **1.36067** 两个不可近似界。）

### 10.7 广义负载均衡（Generalized Load Balancing，*5.5）

- 任务 j 只能运行在**授权机器** M_j ⊆ M 上，目标仍是最小化 makespan。（📌 红字×2：**authorized machine**。）
- **ILP/LP**：x_ij = 机器 i 花在任务 j 上的时间；约束 Σ_i x_ij = t_j、Σ_j x_ij ≤ L、x_ij ≥ 0（LP 松弛去掉授权 0/1 约束）；
- **下界**：L* ≥ LP 最优值 L；L* ≥ max_j t_j。
- **LP 解的结构**：G(x) = { (i, j) : x_ij > 0 }（机-任务二部图）可以做到**无环**（若有环，沿环增广流量消去一条边，反复至无环；流式表述：给定 L 判可行流）。（📌 红字：**acyclic**。）
- **舍入**：G(x) 为森林，以任一机器为根；**叶子任务 → 分给父机器**；**非叶任务 → 分给某个孩子机器**。
- **分析（2-近似）**：叶子任务 j 在父机器上 x_ij = t_j（引理 5）；每台机器至多接收 1 个非叶任务——即 parent(i)（引理 6）⟹ L_i ≤ (叶子部分 = ≤LP 值) + (parent 任务 ≤ max t_j ≤ L*) ⟹ L ≤ 2L*。∎
- 运行时间瓶颈：解一个 mn+1 变量的 LP（可用 m+n+1 点图上的流 + 对 L 二分）；扩展：无关并行机 [Lenstra-Shmoys-Tardos 1990]，2-近似，且除非 P=NP 无 3/2-近似。

### 10.8 背包与 PTAS（Knapsack FPTAS，5.6）

- 背包（优化版）：max Σ v_i x_i s.t. Σ w_i x_i ≤ W；判定版 NP-完全：SUBSET-SUM ≤_P KNAPSACK（v_i = w_i = u_i，目标 V = U）。
- **两个 DP**：
  - DP I：OPT(i, w)：O(nW)——伪多项式（W 的二进制位数使输入规模为 log W）；（📌 红字：**Not polynomial**。）
  - DP II：OPT(i, v) = 恰好产生价值 v 的最小重量：O(n·V*) = O(n²·v_max)——同样伪多项式。（📌 红字：**exactly** v 与 **Not polynomial**。）
- **FPTAS 思想：数值舍入（rounding/scaling）**——把价值"向上"舍入到更小的值域，在舍入实例上跑 DP II：
  - v̂_i = ⌈v_i / b⌉·b，缩放因子 b = ε·v_max / n；
  - 舍入实例上 DP II 时间 O(n·V̂*/b) = O(n²·v̂_max / b) = **O(n³/ε)** ⟹ 关于 n 与 1/ε 都多项式 ⟹ **FPTAS**；
  - 正确性：向上舍入保证舍入实例的最优解集在原实例中可行，且其原值 ≥ (1−ε)·OPT。
- **PTAS 举例**：负载均衡 [Hochbaum-Shmoys 1987]；欧氏 TSP [Arora 1996]——PTAS 以时间换精度。

### 10.9 补充课件：顶点覆盖 / TSP / 子集和的近似

- **顶点覆盖 2-近似（近似算法教材版）**：任取剩余边 (u,v)，把**两端点**都加入 C，删去关联边；|C| = 2|A| ≤ 2|C*|（A 为所选边集，两两不共享端点，C* 须覆盖 A ⟹ |C*| ≥ |A|）。（📌 红字：两个关键不等式 **|C*| ≥ |A|** 与 **|C| = 2|A|**。）
- **TSP 2-近似（三角不等式版）**：① 任选根 r；② Prim 求 MST T；③ **前序遍历** T 得序列 L；④ L 末尾接 r 构成回路 H；
  - 证明：cost(T) ≤ cost(C_OPT)（删去最优回路一条边即生成树）；前序遍历走 W（绕树两周）cost(W) = 2cost(T)；三角不等式下"抄近路" cost(H) ≤ cost(W) ⟹ cost(H) ≤ 2·OPT。∎（📌 红字：三个关键不等式逐条标红；前序遍历定义 **root first → left → right** 亦红字。）
- **一般 TSP 无常数近似**：费用不一定满足三角不等式时，除非 P=NP，对任意常数 ρ > 1 不存在 ρ-近似的多项式算法。
- **子集和**：
  - **精确（指数表）算法** ExactSubsetSum：L[i] = MergeLists(L[i−1], L[i−1]+S[i])，删超 t 元素，返回 max L[n]；
  - **修整（Trimming）**：参数 δ∈(0,1)：删 y 若存在保留元素 z 满足 (1−δ)y ≤ z ≤ y（z 为 y 的"代表"）；例 δ=0.1：⟨10,11,12,15,20,21,22,23,24,29⟩ ⟹ ⟨10,12,15,20,23,29⟩；
  - **ApproxSubsetSum(S, t, ε)**：每次合并后以 δ = ε/n 修整；**定理：是子集和的 FPTAS**（y*/z* ≤ 1+ε；修整后相邻元素比 > 1+ε/2n ⟹ |L_i| = O((n/ε)·log t) ⟹ 多项式）。（📌 红字：**(1+ε)-approximation**、**y*/z\* ≤ 1+ε**、列表大小界 **⌊log_{1+ε/2n} t⌋**。）
